# Single-page tracklet dashboard

Open one tracklet JSON and its matching segmentation masks:

```bash
python -m src.tracking_dashboard --tracklets /path/tracklets_unified.json --masks-dir /path/masks_split
```

With no arguments, the dashboard loads the corrected New-03 tracking specified in
`configs/tracking_evaluation_new03.json`. It opens http://localhost:5011.
If `--masks-dir` is omitted, nearby mask folders are searched, preferring `masks_split`.
Use the exact masks associated with the JSON, especially after unification splits labels.

The single page contains four summary KPIs, a selectable track table, and four timelines for the selected track:

- **Length / recording:** detected frames divided by the full recording frame count. The summary is the median over filtered tracks. Missing frames do not count toward duration.
- **Volume consistency:** population standard deviation / mean segmented volume per track. The summary is the median CV; lower means more consistent. Singletons have no CV.
- **Movement:** centroid displacement in physical units between consecutive observed frames. The summary pools all eligible steps and shows their 95th percentile, with the number exceeding the expected step threshold.
- **Nearby-cell consistency:** fraction of nearby cell identities retained in the next frame. Neighbors are up to five nearest segmented cells within the configured radius. Untracked neighbors remain in the denominator. Summary retention pools retained and eligible neighbors across filtered tracks.

Select a track ID to inspect its duration, relative volume, movement, and neighbor retention on the same page.
Search, minimum duration, and sorting update the displayed population and summary KPIs.
Export track metrics downloads a CSV for that filtered population.

Defaults are Z/Y/X voxel spacing **0.5 / 0.198 / 0.198 µm**, expected maximum step **3 µm**,
neighbor radius **10 µm**, and at most **5 neighbors**. Set these for your recording:

```bash
python -m src.tracking_dashboard --tracklets tracks.json --masks-dir masks \
  --voxel-size-um 0.5 0.198 0.198 --max-step-um 3 --neighbor-radius-um 10 --neighbors 5
```

These are diagnostics without ground truth, not accuracy scores. Real field-of-view exits shorten tracks;
segmentation affects volume; real relative movement changes neighbors. Gaps are excluded from movement
and neighbor comparisons. Missing evidence is displayed as a dash, not a perfect score.
Frame indices are zero-based.

The module saves `outputs/tracklet_dashboard/evaluation.json` and a self-contained
`outputs/tracklet_dashboard/dashboard.html` that opens directly in a browser.
Measurements are cached by input files and settings. Use `--recompute` to force recalculation,
`--evaluate-only` to export without serving, or `--no-browser` on a remote machine.
To access remotely, forward port 5011: `ssh -L 5011:localhost:5011 <server>`.

## Region of interest

Use **Region of interest (JSON)** on the dashboard to upload a saved `roi_selection.json`.
The four KPIs, track table, and CSV then use only selected tracks. **Clear ROI** restores all tracks.
This also works in the standalone HTML export generated by the updated evaluator.

Alternatively launch with the ROI file; its saved `tracklets` path is used automatically:

```bash
python -m src.tracking_dashboard --roi /path/to/unify/roi_selection.json
```

You can also provide `--tracklets` and `--masks-dir` explicitly, or add `"roi": "roi_selection.json"`
to a dashboard config (relative paths resolve from the config directory).

Selection follows the existing ROI workflow: a track is included if its XY centroid falls inside
`roi_first` at `t_first` **or** inside `roi_last` at `t_last`. Coordinates are image pixels.
The selected tracks retain their whole-recording measurements; polygons are not interpolated,
and tracks absent at both specified frames are excluded. Nearby-cell measurements still use
all surrounding detections, including neighbors outside the ROI. Empty selections show no data.
Upload changes affect the open page and CSV; use `--roi` to save the initial selection in the report.
Older exports without centroid coordinates must be regenerated to support ROI uploads.
